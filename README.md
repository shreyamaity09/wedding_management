# wedding_management

Steps to fetch the project and run in local system.
1. Install git from https://git-scm.com/install/windows
2. After successfull installation, run Git Bash from the Wedding Management folder.
3. Use command git clone https://github.com/shreyamaity09/wedding_management.git
4. This command will download the repository in your local system.
5. Open git bash from inside the Cloned repository i.e. wedding_management.
6. Run command git pull.
7. After successfull pull, add your code and commit it from VS Code.
8. Once code is committed, push the changes so that it is stored in GitHub and can be accessed by all the collaborators.

Command for code commit:
git commit -m "Commit message"
In place of commit message add your commit message. E.g.: Adding database configuration

Command for pushing committed changes:
git push

Once changes are pushed, all the pushed changes will be visible in the below link and can be accessed in your local systems by pulling the changes.
https://github.com/shreyamaity09/wedding_management
